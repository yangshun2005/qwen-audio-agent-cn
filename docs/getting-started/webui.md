# WebUI

WebUI 是浏览器会话客户端。Gateway 在其自身源上以静态页面形式提供该客户端——无需部署独立的前端服务。

## 打开

在 Gateway 运行的情况下，在另一个终端中打开 WebUI：

```bash
qwenaudio webui
```

此命令会打印页面 URL（默认为 `http://127.0.0.1:3101`）并在默认浏览器中打开。浏览器在首次使用时请求麦克风权限；请允许以启用语音功能。

选项：

| 选项 | 含义 |
| --- | --- |
| `--url URL` | 连接到其他地址的 Gateway（默认为 `http://127.0.0.1:3101`） |
| `--session ID` | 恢复特定的语音会话 |
| `--no-open` | 仅打印 URL，不打开浏览器 |

## 你可以做什么

- **全双工语音** — 自然说话和打断，并带有实时转录。
- **文本和附件** — 输入消息或添加图片和文件。普通附件可由后端处理；语音模型无需直接理解图像。
- **任务视图** — 跟踪分派给后端代理的后台任务，包括进度和最终结果。

有关普通文件与实时视觉捕获之间的区别，请参阅[会话与附件](../guides/conversation.md)。
顶部的“知识库”按钮用于[导入主机文档](../guides/knowledge.md)，而非聊天附件。

## 与其他客户端的关系

TUI、WebUI 和桌面 orb 均使用相同的 Gateway 客户端协议。一个 Gateway 接受**每个用户一个活动客户端连接**；另一个客户端可在确认后接管，断开前一个客户端的连接。桌面应用还可以在共享 CLI 用户配置的同时运行自己的 Gateway 进程。相同的 WebUI 页面驱动桌面会话窗口，因此各界面上的呈现行为保持一致。

> 将 WebUI 暴露到本机之外会跨越信任边界：请在前面放置带有身份验证的 HTTPS 反向代理，并遵循[远程访问安全](../configuration/advanced.md#remote-access-security)。
