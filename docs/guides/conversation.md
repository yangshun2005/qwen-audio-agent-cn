# 对话与附件

语音、文本和附件共享同一个对话。前端负责处理聊天和已配置的工具，在需要执行时调用后端。并非每次发言都会产生后端工作。

## 语音与文本

- 在 WebUI 或桌面端对话面板中允许麦克风访问即可说话，也可以输入并发送文本。
- 静音会停止向语音前端输入麦克风声音，但不会取消正在执行的工作，也不会禁用结果播报。
- **发送**文本或附件会优先处理该手动输入，并中断当前的前端回复。
  编辑文本或选择/粘贴附件不会触发发送，也不会主动中断播放。
- 终端命令及平台音频差异请参阅 [TUI](../getting-started/tui.md)。

## 图片与文件

在 WebUI 和桌面端面板中，可使用“＋”按钮、拖放或粘贴的方式添加附件，然后发送。
每个附件大小限制为 8 MB；每轮对话总大小限制为 12 MB。TUI 有独立的本地路径输入流程，详见其指南。

普通附件与实时视觉输入有所不同：

| 输入 | 处理方式 |
| --- | --- |
| 图片 / 文件附件 | 前端获取引用和摘要，并可将原始文件转发给具备处理能力的后端 Agent。 |
| 实时视觉帧 | 当客户端和语音 Provider 支持持续视觉采集时可用；目前仅在 WebUI 中使用。 |

不具备直接图像理解能力的语音前端仍可接受图片附件，交由后端处理。
如果未配置具备相应能力的后端，则文件处理请求无法完成。
发送附件时请附上简短指令（例如“描述这张图片”），以使请求意图更明确。
聊天附件不会自动进入[知识库](knowledge.md)。

## 历史记录与新对话

对话区域会显示语音转写文本、助手回复和后端工作卡片。开启新的前端对话不会清除长期记忆，也不能用于取消后端工作。
如需取消，请明确请求取消并检查最终状态；参见[工作与权限](tasks.md)。

## 切换客户端

每个用户在 Gateway 上只能有一个活跃客户端。在新客户端中确认接管后，会断开之前的连接。
桌面端自带的 Gateway 与 CLI Gateway 默认使用独立的运行时；参见[实例与客户端](../operations/gateway.md#instances-and-clients)。
