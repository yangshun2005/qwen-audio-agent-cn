# 对话与附件

语音、文字和附件使用同一条对话。前台负责处理聊天内容及已配置的工具，只有在需要实际执行时才调用后台；并非每句话都会创建后台工作。

## 语音与文字

- 在 WebUI 或桌面对话面板中，允许麦克风权限后即可说话；也可以直接输入文字发送。
- 静音仅停止将麦克风输入交给语音前台，不会取消后台工作或关闭结果播报。
- **发送**文字或附件会优先处理本轮手动输入，并打断正在进行的前台回复；仅编辑文字、选择或粘贴附件不会发送，也不会主动打断。
- TUI 的命令和平台音频差异请参阅[TUI 指南](../getting-started/tui.zh.md)。

## 图片与文件

WebUI 和桌面对话面板支持通过“＋”、拖入或粘贴添加附件；确认后点击发送。单个附件最大 8 MB，单轮合计最大 12 MB。TUI 的本地路径输入请参阅其专门指南。

普通附件与实时视觉输入不是一回事：

| 输入方式 | 如何处理 |
| --- | --- |
| 图片 / 文件附件 | 前台获得附件引用与摘要，需要时把原始文件交给有能力的后台 Agent。 |
| 实时视觉帧 | 客户端与语音 Provider 都支持时，持续采集并发送画面；当前从 WebUI 使用。 |

因此，语音前台不能直接看图并不代表不能发送图片；但若后台未配置或不支持相应文件时，助手无法完成文件处理。可以将图片与“描述这张图”等文字一起发送，以减少指代歧义。仅将附件放入聊天不会自动加入资料库；长期检索请使用[资料库](knowledge.zh.md)。

## 历史与新会话

对话区显示语音转写、助手回答和后台工作卡片。新会话用于开始新的前台对话，不等同于清空长期记忆，也不能用它代替取消后台工作。需要停止工作时，请明确要求取消，并确认最终状态；详见[后台工作与授权](tasks.zh.md)。

## 切换客户端

同一 Gateway 中每个用户只有一个活动客户端。新客户端确认接管后，旧连接会断开。桌面版自带 Gateway 与 CLI Gateway 的运行时则默认独立；详见[实例与客户端](../operations/gateway.zh.md#实例与客户端)。
