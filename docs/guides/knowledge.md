# 知识库

知识库让助手能够在您的文档中查找证据。内置实现采用轻量级本地关键词检索，无需单独的向量数据库或 Embedding 模型。如需更丰富的语义和图检索，请参阅 [LightRAG 示例](../scenarios/lightrag.md)。

## 1. 启用知识库

在 Gateway 使用的 `config.env` 中进行如下设置：

```dotenv
QWEN_AUDIO_DOMAIN_LIBRARY=on
```

[根据您的运行模式重启](../operations/gateway.md#applying-configuration-changes)。
如果您显式禁用了 `QWEN_AUDIO_KNOWLEDGE_TOOL_ENABLED`，请将其恢复为 `true`；
否则，文档管理可以正常工作，但前端将没有检索工具。
语音 Provider 必须支持工具调用。

## 2. 导入文档

1. 打开连接到该 Gateway 的 **WebUI**，点击顶部的“知识库”。
2. 粘贴 **Gateway 主机上的绝对文件路径**，例如 `/Users/me/Documents/handbook.md`。
3. 点击“添加到知识库”并等待导入完成。文档出现在列表中后即可提问。

这不是文件上传工具。远程手机上的路径并不指向计算机上的文件；
请先将文档放置在 Gateway 主机上。桌面端 Orb 和会话面板目前不提供知识库管理按钮。

| 文件类型 | 内置处理方式 |
| --- | --- |
| Markdown、TXT 及类似文本 | 直接导入；无需后端 Agent。 |
| PDF、Word、PPT 及其他复杂文档 | 由支持隔离执行的后端配置转换为 Markdown；转换效果取决于其工具。 |

复杂文档使用隔离的执行会话，而非日常的协调者对话，且不继承语音聊天上下文。导入错误会显示在面板中。如果没有可用的转换器，请在导入前自行将文档转换为 Markdown 或 TXT 格式。

## 3. 查询与移除

例如，可以这样提问：“搜索知识库：手册中关于发布流程是怎么说的？”
内置检索会返回按标题和正文关键词匹配的源文摘录；前端负责组织答案。它并非完整的语义检索系统。如果结果不理想，可以尝试使用文档自身的术语或提出更精确的问题。

“移除”操作会删除知识库中的副本及其可搜索内容，但不会删除原始源文件。聊天附件不会自动导入。源文件的更改也不会自动同步；请重新导入更新后的内容。

## 数据与其他知识系统

内置知识库数据存储在 Gateway 主机上。使用云端语音模型时，检索到的摘录会作为答案上下文发送给该模型。复杂文档转换也会使用后端配置的模型和工具。请确认这些服务适合所处理的文档。

如需复用其他知识系统，请参阅 [LightRAG](../scenarios/lightrag.md)。
有关适配器开发，请参阅 [Knowledge Provider 接口](../reference/knowledge.md)。
