# 故障排查

首先确定受影响的层级：**客户端 → 网关 → 语音前端 / 后端代理 / 前端工具**。
网关连接正常并不代表模型连接正常；已安装后端也不代表凭据有效。

## 收集基本信息

检查客户端和网关的版本、运行模式，以及所选的语音前端和后端代理。
CLI 命令：

```bash
qwenaudio --version
qwenaudio doctor
qwenaudio setup
```

开发版本包含只读的 `doctor` 命令：它不会启动模型、后端或麦克风，也不会自动更改配置。`setup` 命令检查后端可执行文件和集成组件，但不检查身份验证、API 密钥或配额。在没有活跃语音会话的情况下，诊断报告会将语音连接标记为“未验证”。请完成一次真实对话以进行验证。

## 连接与配置

| 症状 | 检查与操作 |
| --- | --- |
| 网关已断开 | 确认网关正在运行，且客户端使用的是其实际地址和端口。桌面端和 CLI 默认拥有独立的运行时；请检查正确的实例。 |
| 网关已连接，但语音前端不可用 | 检查语音服务地址、凭据、配额以及 Provider 错误。仅凭 Orb 动画不能证明连接正常。 |
| 配置更改未生效 | 使用 `qwenaudio config` 查找配置文件，检查环境变量 / 源 `.env.local` 覆盖项，并重启实际的网关。 |
| `gateway restart` 提示服务未安装 | 该命令仅管理用户后台服务。请在终端中手动重启；应用设置或重新打开桌面端。 |
| 客户端被占用或被接管 | 每个用户对每个网关仅有一个活跃连接。请确认接管或关闭其他客户端。 |

参见 [运行网关](gateway.md) 和 [配置目录](../configuration.md)。

## 麦克风与播放

| 症状 | 检查与操作 |
| --- | --- |
| 无麦克风输入 | 检查应用/浏览器麦克风权限、系统输入设备、静音状态和休眠状态。 |
| 插拔耳机后出现问题 | 确认系统输入/输出已切换到预期设备。如有需要，重新打开客户端并记录设备型号和切换顺序。 |
| 出现文字但没有音频 | 检查输出设备、音量和客户端播放状态。对于本地语音服务，还需检查其 TTS 日志。 |
| 扬声器回声打断回复 | 在 Linux / Windows 上优先使用半双工 TUI；在没有 AEC 的情况下进行全双工通话时请佩戴耳机。 |
| 远程浏览器无法访问麦克风 | 使用受信任的 HTTPS 并授予权限，不要使用普通的远程 HTTP 地址。 |

音频模式参见 [TUI](../getting-started/tui.md)。休眠会隐藏桌面端并停止向语音前端输入麦克风数据，同时保持 Realtime 连接。唤醒词检测在启用时于本地运行。

## 后端与工具

- 后端执行失败：使用 `qwenaudio setup --backend <name>` 检查安装情况，然后在后端自身的界面中验证身份验证和模型。
- 未指定后端模型：网关不会猜测默认值；它使用 Agent 的配置。
- 显式模型覆盖失败：后端必须暴露标准的 ACP 模型配置并接受该值。请遵循错误提示；不要假设会静默回退。
- MCP 命令缺失：检查 `command` 和 PATH。安装命令后重启；`gateway restart` 会刷新后台服务的路径缓存。
- MCP 环境变量缺失：将其放入该网关的 `config.env` 中，而不是在另一个终端中临时导出。
- 知识库不可用或导入失败：启用它并使用网关主机路径。复杂文档还需要隔离的转换支持。

参见 [MCP 配置](../reference/frontend-mcp.md) 和 [知识库](../guides/knowledge.md)。

## 远程连接

对于 Tailnet，请检查官方 Tailscale 是否在两台设备上均在线、它们是否共享同一个 tailnet、访问策略是否允许该连接，以及网关 HTTPS 发布是否就绪。对于局域网，请检查子网、防火墙，以及网关是否使用 `--lan` 参数启动。对于外部 HTTPS 端点，请检查证书、反向代理设置和 WebSocket 转发。连接代码仅显示一次；如果泄露，请吊销该设备并生成另一个代码。
参见 [远程连接](remote-access.md)。

## 日志与报告

桌面端在“设置 → 应用 → 日志”中显示其日志目录。CLI 日志默认位于 `~/.config/qwaudio/state/logs`；桌面端托管的网关日志位于 `~/.config/qwaudio/state/desktop/logs`。桌面客户端日志使用其应用程序数据目录下的 `logs/` 子目录。

开发版本可以汇总已记录的对话轮次：

```bash
qwenaudio doctor --turn <turnId>
```

有关范围和限制，请参见 [只读诊断](../configuration/advanced.md#read-only-diagnostics)。

**请勿包含 API 密钥、配对码、设备令牌、完整配置文件或未经审查的私人对话。**
