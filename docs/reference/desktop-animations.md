# 桌面动画集成

桌面端并不会将所有业务信号都扁平化为单一的“Agent 状态”。生命周期、运行时就绪、语音交互以及后台工作仍然彼此分离；皮肤仅消费稳定的展示状态和一次性事件。

| 标准动画 | 含义 | Agent 状态或事件 | 播放方式 |
| --- | --- | --- | --- |
| `idle` | 休息中 | `idle`、`connecting`、`occupied` | 状态持续期间循环播放 |
| `running-right` | 向右移动 | 用户将宠物向右拖拽 | 拖拽期间循环播放 |
| `running-left` | 向左移动 | 用户将宠物向左拖拽 | 拖拽期间循环播放 |
| `waving` | 说话中 | `speaking` | 在完整 `speaking` 状态期间循环播放 |
| `jumping` | 成功 / 唤醒 | `waking`、首次启动就绪、任务成功完成、指针进入 | 每个事件播放一次 |
| `failed` | 失败 | `error`、桌面运行时故障、任务失败 | 每个事件播放一次 |
| `waiting` | 聆听中 | `listening` | 在完整 `listening` 状态期间循环播放 |
| `running` | 工作中 / 启动中 | `working`、`starting` | 状态持续期间循环播放 |
| `review` | 前台轮次处理 | `processing` | 每个处理阶段播放一次 |

持续状态与一次性事件分别进行仲裁：启动、聆听、说话以及后台工作保留其循环轨道，而首次就绪、唤醒、任务结果、前台处理以及指针进入则各播放一次。一次性动作会恢复当前的基础轨道：若仍有工作处于活动状态则播放 `running`，否则播放 `idle`。每个活动后台任务均使用 `working` → `running` 的过渡，包括后端思考过程；待处理的授权不会选择 Agent 动画，而是保留在任务界面中可见，直到其语音请求自然进入 `speaking` 状态。所有任务类型均遵循相同的启动、完成和失败规则。纯前端模式会跳过后端就绪检查。皮肤包仅为静态资源（JSON + WebP），并在导入时进行校验；如果所选皮肤包被移除，orb 将回退到内置外观。

资源格式请参阅 [宠物皮肤协议](../desktop/pet-skin-spec.md)，日常使用请参阅 [桌面端](../desktop/overview.md)。
