# i18n 一致性追踪

> 面向维护者的双语文档站点策略。此文件
> 不通过 `scripts/sync-docs-site.mjs` 发布。

已发布手册中无已知的中英文内容差异。

## 构建时保护

每个已发布的 Markdown 页面必须配有对应的语言版本：

- `page.md` — 英文源文件；
- `page.zh.md` — 中文源文件。

当任一侧缺失时，`npm run docs:build` 将失败。由 `scripts/sync-docs-site.mjs` 明确排除的仅维护者可见的文件和目录不参与此检查。

## 策略

- 在同一变更中同时更新两种语言的文件。
- 保持章节结构和技术含义一致；不要求逐句直译。
- 产品名称、协议标识符、命令、环境变量及功能名称在两种语言中必须保持一致。
- 仅包含单一语言的文件必须明确从发布站点中排除，而非在无对应版本的情况下静默发布。
