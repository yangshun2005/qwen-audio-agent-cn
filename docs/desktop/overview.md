# 桌面版

桌面版提供了一个带有语音球和对话面板的界面，并内置了网关；无需先启动终端服务。默认情况下，配置、记忆和工作区与命令行版共享，但运行时目录是独立的。如果同一桌面版运行时目录中已有网关在运行，则会复用该网关；否则，应用会自行启动并管理一个网关。

## 首次运行

1. 从[发布页面](https://github.com/QwenAudio/qwen-audio-agent/releases/latest)下载安装程序并打开应用。
2. 首次启动会创建 `config.env`。打开设置，为你的语音前端输入凭据。对于默认的 DashScope 服务，设置中会提供百炼 API 密钥页面的链接。
3. 选择一个后端智能体，或以仅前端模式启动。已安装的智能体会复用其身份验证和模型设置。如果缺失，请使用可用的安装操作并完成后端的设置。
4. 点击“应用”，检查网关、语音前端和后端智能体的状态。
5. 允许麦克风权限，说“你好”，并确认你看到了对话记录并听到了回复。

启动时会复用现有配置。已填写的设置或已安装的后端并不能证明凭据有效或配额充足。有关错误信息，请参阅[故障排除](../operations/troubleshooting.md)。

## 语音球与对话面板

使用语音球旁边的“打开对话”按钮来打开面板。面板会显示对话和工作卡片，并支持文本、图片和文件输入。面板和语音球是同一客户端的两种视图，而非独立的语音连接。面板的折叠按钮可返回语音球视图。

点击语音球本身不会切换静音状态。请使用麦克风按钮；静音不会停止当前或未来的回复。有关手动输入行为，请参阅[对话与附件](../guides/conversation.md)。

## 后端智能体连接

默认情况下，应用会管理所选的后端。支持外部服务的智能体可以提供“连接到现有服务”选项，并附带地址和可选令牌；OpenClaw 目前支持此功能。此选项选择的是**后端智能体服务**，而非桌面版客户端的另一个网关。请参阅[后端设置](../configuration/backend.md)。

## 语音球与自动休眠

在配置的空闲时间过后，语音球可以自动隐藏。你也可以要求它进入待机状态。休眠会**隐藏界面并停止向语音前端输入麦克风声音，同时保持实时连接和对话上下文**。应用会保留在菜单栏中；后端工作不会被取消，待处理的通知会在唤醒后继续播报。

你可以从菜单栏或显示快捷键唤醒它。macOS 的默认快捷键是 `⇧⌘ 空格键`；你可以在设置中查看或更改实际绑定。如果启用了唤醒词检测，麦克风在休眠期间仅用于本地关键词检测。说“你好千问”即可唤醒。首次启用会下载并验证一个约 33 MB 的 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) 模型，之后会复用其缓存。检测在独立的桌面版工作进程中运行；唤醒词音频不会被上传。

## 皮肤

在“设置”→“应用”→“外观”中，点击“导入皮肤…”并选择一个皮肤目录、`pet.json` 文件或 zip 压缩包。导入的皮肤可以被选择或删除；内置外观无法删除。

支持 Codex 宠物包和可选的动画帧描述；但并非必须使用 Codex。有关资源创建，请参阅[宠物皮肤协议](pet-skin-spec.md)；有关状态映射、循环和单次播放，请参阅[桌面版动画集成](../reference/desktop-animations.md)。

## 远程连接

在“设置”→“应用”→“网关”中输入本地或远程网关 URL，然后点击“应用”。对于首次连接到需要身份验证的远程网关，请将其主机上生成的完整配对链接粘贴到同一字段中。桌面版会自动配对，然后显示纯 URL，并在后续连接中复用保存的凭据。请参阅[远程连接与配对](../operations/remote-access.md)。网关和后端智能体保留在远程主机上；桌面版仅处理输入和输出，不提供自己的中继服务。Tailnet 模式要求两台设备都安装官方 Tailscale；局域网和外部 HTTPS 端点则不需要。

## 安装

有关稳定版软件包和更新，请参阅[安装与更新](../getting-started/install.md#desktop-installation)。在已安装依赖项的源码检出目录中，构建本地测试包：

```bash
npm run desktop:build:local      # macOS
npm run desktop:build:win        # Windows
npm run desktop:build:linux      # Linux: AppImage + deb
```

输出文件位于 `dist/desktop/`。本地测试构建不等同于官方签名发布版本。

## 数据目录与隔离

桌面版托管的网关和命令行版托管的网关共享配置、身份、记忆和工作区，但运行时状态是分开的。桌面版偏好设置、窗口位置、皮肤、唤醒词模型和连接凭据存储在客户端应用程序目录中。两者可以同时运行，但这并不意味着它们连接到同一个网关。有关路径和覆盖项，请参阅[配置目录](../configuration.md#configuration-and-data-directories)。

## 自动更新与日志

在设置中检查更新，下载完成后重启。退出会停止此应用启动的网关和后端进程，但不会停止借用或远程的服务。

通过“设置”→“应用”→“日志”打开此桌面版运行时的日志目录。日志会经过编辑和轮转。有关配置，请参阅[本地日志](../configuration/advanced.md#local-logs)。
